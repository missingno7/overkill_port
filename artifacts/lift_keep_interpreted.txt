# Busy-wait spin loops whose exit depends on an ASYNCHRONOUS event (a timer/
# keyboard IRQ setting a flag, a CRT retrace bit toggling).  A plain lift of the
# spin freezes an iteration count that is really timing-dependent -- liftverify
# proves it DIVERGES against the interpreted oracle (2026-07-17e: 1010:0679
# flagged DIVERGED, the timer wait).  They are the manifest's enumerated,
# fail-loud env-wait FRONTIER: kept interpreted (tagged env_wait in the IR) until
# modelled as an explicit scheduler-yield boundary in the standalone runtime.
#
# overkill already treats both as wait boundaries (overkill/input_waits.py).
