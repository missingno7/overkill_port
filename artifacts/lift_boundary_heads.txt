# OVERKILL boundary-head recovery facts (DOS_RE 2.0, docs/dos_re_2.0.md §6a).
#
# A boundary head is a scheduler-yield point: the address where a top-level
# loop yields one frame to the host instead of returning. Declaring it lets the
# CFG scanner treat the game's own infinite main loop as a liftable coroutine
# (cfg.scan_function) and the emitter turn the site into a boundary event +
# ResumePoint (emit.py), rather than refusing the loop `no-exit`.
#
# Evidence: all 10 no-exit census entries in the 96C5..9928 gameplay-loop region
# scan into the SAME strongly-connected loop and every one reaches the frame
# boundary call below (verified: scripts/probe_vmless_cpuless.py + the CFG scan).
# This is the same boundary the demo-lockstep gate snapshots at (1010:9B2E).
#
# 1010:97CB -- `call 9B2E`, the per-frame boundary of the gameplay main loop
#              (1010:97B2). One frame == one traversal from the resume point
#              back to this call. Gives all 10 no-exit entries a modelled exit.
1010:97CB

# 1010:0679 -- the TIMER TICK ENV-WAIT: `cmp byte cs:[066B],0 ; jz self ; ret`.
#              The IRQ0 ISR 1010:06E5 -> 1010:066C does `inc byte cs:[066B]`;
#              this spins until it does.  A CPUless build has no asynchronous
#              interrupt, so the flag never changes on its own and the wait is
#              unsatisfiable: measured, `1010:96C8 -> CBE8 -> CF2E -> 0679` runs
#              the generated body to its 20M-iteration spin guard.
#
#              Declaring it a HEAD is what makes the GENERATED SPINE own the
#              yield: the emitted body calls `plat.boundary(1010, 0679, 067F,
#              regs, cost)` inside the poll loop, and a frame driver installed
#              on `plat.boundary_cb` decides whether to park.  The alternative
#              -- intercepting the address with a host override -- is
#              host-created flow that BYPASSES the spine, and it was also
#              silently broken (it called the WRONG `boundary`; see the
#              retired `_timer_env_wait` in git history).
#
#              MEASURED COST of declaring it: promotable stays 623/626 and the
#              refusal buckets are unchanged (only the 3 structural
#              ir-not-liftable).  Parking grows 10 -> 20 functions, which lose
#              their CPU-ABI adapters: 0679 itself plus 558B 5559 CBE8 CF2E
#              CF78 D007 D305 D318 D390.  NONE of those ten appears in either
#              verification ledger (artifacts/verify_ledger_L1.json,
#              verify_ledger_coldstart.json), so the per-function differential
#              loses NO proven coverage.
#
# NOT DECLARED, and here is the measurement so nobody re-tries it blind:
#   1010:50C9 (the CRTC retrace wait) REGRESSES the corpus badly -- promotable
#   623 -> 585, `contains-call` 0 -> 37, `boundary-head-on-transfer` 0 -> 1.
#   It is a thunk (`jmp C9EA ; call C9F1 ; call CA02 ; ret`) with ~20 static
#   callers, so the head lands on a transfer and the refusal cascades. If the
#   retrace pacing is ever needed as a head it must be declared at the real
#   polling site inside C9F1/CA02, not at the thunk.
#
#   1010:C9FC IS THAT REAL POLLING SITE, and it was located and PRICED
#   2026-07-18m -- both halves of the trade are recorded here so the next agent
#   inherits them together. It is block 0 of func_1010_ca02:
#       in al,dx (dx=3DA) ; test al,8 ; jz self
#   MEASURED, declaring it (vs the shipped heads):
#     * liftable UNCHANGED at 623/626, refusal buckets unchanged, and only two
#       IR functions move (C9F1, CA02) -- so by the CENSUS it looks free;
#     * but the CORPUS prices it differently: PARKING GROWS 20 -> 42.  Twenty-two
#       functions lose their CPU-ABI adapters: 0011 0030 0136 50C9 587E 58DF
#       5C35 5C46 5C74 5C9A 9844 C9F1 CA02 CC04 CCAA CCC4 CCF0 CD8D CDA7 CDAA
#       CE40 CE5C.  Six of them (58DF 50C9 5C46 5C74 CE40 CE5C) carry verdicts in
#       verify_ledger_coldstart.json -- all INCONCLUSIVE, none PASS -- so no
#       PROVEN coverage is destroyed, but those six become permanently unprovable
#       by the per-function differential while parked.
#   DECLINED 2026-07-18m: a real permanent cost against a still-hypothetical
#   benefit.  Declare it only when something concrete needs a retrace-cut frame.
#
#   THE GENERAL LESSON, and the reason this note is long: THE LIFTABLE COUNT AND
#   THE PARKING COUNT ARE DIFFERENT COST FUNCTIONS.  close_census.py's
#   liftable=N/M says a head does not break the lift; only
#   cpuless_promote.py --apply says what it costs.  Quote the SECOND before
#   calling any head declaration free.  (Ungated control for that comparison:
#   regenerating with the SHIPPED heads must reproduce the committed corpus
#   byte-identically -- it does, 625 modules.)
#   1010:5160 (EGA display-start) is a genuine 3DA poll but is gated on video
#   mode [95BC]==1, i.e. it is dead on the Tandy path this port runs.
#   1010:06E5 and 1010:0672 are NOT waits at all despite sitting in
#   hook_taxonomy's env_wait set: 06E5 IS the IRQ0 ISR (the producer of the
#   tick 0679 consumes) and 0672 clears the flag. Declaring either would be a
#   category error.
1010:0679
